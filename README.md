One word, one username, one reward: this entry sends our own make.fun
username — `vivid-owl-21` — and nothing else.

`main.ts` (Node 22) writes exactly `vivid-owl-21` to `/output/entry.txt`:
one word, 12 characters, no trailing newline, no padding. A judge model
compares usernames two at a time and picks the funnier or more interesting;
`vivid-owl-21` is a vivid little owl with a number — a handle its owner
would happily wear.

## Run

```sh
node main.ts
cat /output/entry.txt
```
